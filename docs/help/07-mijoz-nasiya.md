# Mijoz va nasiya

## Mijoz qanday qo'shaman?
Kalit: mijoz qo'shish, yangi mijoz, xaridor, klient, telefon

Sotuv paytida (POS):

1. Savatdagi **Mijoz tanlang** tugmasini bosing.
2. **+ Yangi mijoz** ni bosing.
3. **Ism** va **Telefon** (majburiy), kerak bo'lsa **Chegirma %**.
4. **Qo'shish va tanlash** — mijoz shu sotuvga darhol tanlanadi.

Admin panelda:

1. **Mijozlar** → yuqori o'ngdagi **Mijoz qo'shish**.
2. **Ism**, **Telefon**, **Chegirma % (0–100)**.
3. **Saqlash**.

Mijozga chegirma % yozsangiz, POS'da u tanlanganda chegirma o'zi qo'llanadi.

## Qarzni qanday to'layman?
Kalit: qarz to'lash, nasiya to'lash, qarzini berdi, qarz yopish, fifo

Mijoz qarzini to'lashga keldi:

1. Admin panel → **Nasiya / Qarz**.
2. Mijozni **Ism yoki telefon** bo'yicha toping.
3. Ikki yo'l:
   - **Umumiy to'lov (FIFO)** — mijoz bergan summani yozasiz, dastur uni **eng eski qarzdan boshlab** o'zi taqsimlaydi. Bir nechta qarzi bo'lsa — shu qulay.
   - Qarz qatoridagi **To'lash** — faqat shu bitta qarzga.
4. Summani yozing va tasdiqlang.

Qarz kartochkasidan ham bo'ladi: mijoz ismini bosing → **Qarz kartochkasi** → **Qarzni to'lash**.

- To'liq yopilgan qarz **✓ To'langan** holatiga o'tadi, qisman to'langani — **⏳ Qisman**.

## Qarz kartochkasi nima?
Kalit: qarz kartochkasi, qarz tarixi, akt sverka, mijoz qarzi, oborot

**Qarz kartochkasi** — bitta mijozning barcha nasiya va to'lovlari bitta varaqda: sana, hujjat (chek raqami yoki to'lov), summa va qolgan qarz.

Ochish: Admin panel → **Nasiya / Qarz** → mijoz **ismini** bosing.

- Kartochkadagi jami qoldiq **Nasiya / Qarz** ro'yxatidagi raqam bilan bir xil.
- Chek raqamini bosing — o'sha nasiyada qaysi mahsulotlar olingani ochiladi.
- Mijoz "qancha qarzim bor, qachon nima oldim?" desa — shu kartochkani ko'rsating.
- Kartochka pastidagi **Qarzni to'lash** — shu mijoz uchun FIFO to'lov.
